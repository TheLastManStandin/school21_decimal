# s21_decimal

Реализация собственной библиотеки `s21_decimal` на языке C для работы с десятичными числами высокой точности.

## О проекте

`s21_decimal` — это аналог decimal-типа, предназначенный для точных финансовых и математических вычислений, где недопустимы ошибки округления, характерные для `float` и `double`.

Библиотека реализует арифметические операции, сравнение decimal-чисел, преобразование типов, округление и вспомогательные функции, а также работу с внутренним двоичным представлением числа.

Проект разработан в соответствии со стандартом C11 без использования `__int128`.

## Возможности

### Арифметика
- Сложение
- Вычитание
- Умножение
- Деление

### Сравнение decimal между собой
- `<`, `<=`, `>`, `>=`, `==`, `!=`

### Конвертация
- `int -> decimal`
- `float -> decimal`
- `decimal -> int`
- `decimal -> float`

### Дополнительные функции

- `floor` — округление decimal-числа вниз до ближайшего целого числа.
- `round` — округление decimal-числа до ближайшего целого по правилам математического округления.
- `truncate` — отбрасывание дробной части числа без округления.
- `negate` — изменение знака числа на противоположный.

## Особенности реализации

- Собственное представление decimal-числа через битовые операции
- 96-битная мантисса
- Поддержка scale от 0 до 28
- Поддержка знака числа
- Банковское округление
- Обработка переполнений и ошибок вычислений
- Unit-тесты для основных функций

